# To-Do List Application using Python

## About the Project
This is a simple To-Do List application developed using Python. It helps users manage their daily tasks by adding, viewing, and deleting tasks.

This project was created as part of my CodSoft Python Programming Internship.

## Features
- Add new tasks
- View all tasks
- Delete tasks
- Simple menu-driven interface
- Easy to use

## Technologies Used
- Python
- VS Code

## Concepts Used
- Lists
- While loops
- Conditional statements
- For loops
- User input

## How to Run
1. Download or clone this repository.
2. Open the project in VS Code.
3. Run the following command:

`python todo_list.py`
